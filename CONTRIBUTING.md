# Contribuição

Consulte a [visão do projeto](docs/PROJECT.md) e as [instruções de execução](docs/DEVELOPMENT.md).

## Antes de alterar

Este clone contém uma distribuição compilada. Preserve os arquivos com hash de `assets/` enquanto os fontes originais não forem recuperados. Para mudanças de comportamento, registre a limitação e recupere o projeto de desenvolvimento antes de editar e recompilar.

Correções de documentação, metadados e ferramentas podem ser feitas diretamente. Use UTF-8, dois espaços e nomes claros. Não inclua credenciais, dependências instaladas, logs, caches ou gravações temporárias.

## Enviar uma alteração

1. Descreva o problema e o comportamento esperado.
2. Faça uma mudança de escopo claro.
3. Execute `node scripts/check.mjs`.
4. Para alteração visual, anexe capturas reais e informe viewport e navegador.
5. Atualize a documentação afetada.

Não atribua métricas comerciais ou recursos de IA generativa ao projeto sem implementação e evidência. O modelo de PR ajuda a registrar escopo, validação e limitações.
